개인정보처리방침

모두의 인성측정 · 시행일 2026년 11월 26일

요약: 이 앱은 회원가입이 없고 서버도 없습니다. 사진과 얼굴 측정값은 사용자의 기기 안에서만 처리하며, 운영자에게 전송하거나 저장하지 않습니다. 다만 얼굴 인식에 쓰는 Google의 라이브러리가 성능·사용량 지표를 Google로 전송합니다.

1. 적용 범위

이 방침은 "모두의 인성측정" 웹 서비스(https://seungiljang.github.io/ai-human-scanner/)와 같은 내용을 담은 모바일 앱에 적용됩니다. 이 앱은 얼굴 사진의 비율을 측정해 오락용 관상 풀이와 점수를 보여주며, 실제 인성이나 성격을 평가하지 않습니다.

2. 운영자가 수집하는 개인정보

운영자는 사용자의 개인정보를 수집하지 않습니다.

  • 회원가입, 로그인, 이름·연락처 입력이 없습니다.
  • 운영자가 관리하는 서버나 데이터베이스가 없습니다.
  • 광고, 방문 통계, 추적 도구를 넣지 않았고 쿠키를 사용하지 않습니다.

3. 사진과 얼굴 정보의 처리

항목처리 방식
카메라 영상, 선택한 사진기기 안에서만 처리합니다. 기기 밖으로 전송하지 않고 기기에도 저장하지 않습니다.
얼굴 특징점과 측정값(눈·코·입 등의 비율과 각도)점수와 풀이를 계산하는 동안만 기기의 메모리에 둡니다. 특정 개인을 식별하거나 다른 사진과 대조하는 데 쓰지 않습니다.
보유 기간홈 화면으로 돌아가거나 다시 분석하거나 앱을 닫으면 사진과 측정값을 지웁니다.

다른 사람을 촬영하거나 다른 사람의 사진을 사용할 때는 반드시 그 사람의 동의를 받아 주세요.

4. 제3자가 처리하는 정보

제3자내용
Google (MediaPipe) 얼굴 인식에 Google의 MediaPipe 라이브러리를 사용합니다. Google의 안내에 따르면 입력 이미지는 기기에서 처리되어 Google 서버로 전송되지 않지만, 라이브러리의 성능·사용량 지표는 Google로 전송되며 Google의 개인정보처리방침에 따라 처리됩니다.
MediaPipe 개인정보 안내 · Google 개인정보처리방침
GitHub (GitHub Pages) 웹 서비스의 파일은 GitHub Pages에서 제공됩니다. 접속할 때 GitHub가 IP 주소 등 접속 기록을 보안과 운영 목적으로 처리할 수 있습니다. 운영자는 이 기록을 받거나 볼 수 없습니다.
GitHub 개인정보처리방침

분석을 시작하면 위 내용에 동의한 것으로 봅니다. 동의하지 않으면 분석 기능을 사용하지 말아 주세요.

5. 기기 권한과 기기에 저장되는 것

  • 카메라: 얼굴 촬영 화면에서만 사용합니다. 권한을 거부해도 사진 선택으로 이용할 수 있습니다.
  • 사진 선택: 사용자가 직접 고른 사진 한 장만 읽습니다. 사진 보관함 전체에 접근하지 않습니다.
  • 앱 파일 캐시: 다음에 빠르게 열리도록 앱 화면 파일과 얼굴 인식 모델 파일을 기기에 캐시합니다. 사진, 측정값, 결과는 캐시에 들어가지 않습니다.

6. 결과 공유

공유 버튼을 누르면 사용자가 고른 앱(메신저 등)으로 점수와 등급이 담긴 문구, 링크, 결과 이미지가 전달됩니다. 공유한 뒤의 내용은 해당 앱의 정책에 따라 처리됩니다.

  • 링크에 담기는 것: 받는 사람이 결과 전체를 볼 수 있도록, 링크 주소에 점수, 등급, 가장 좋은 운과 주의할 점, 부위별 풀이 결과(예: "긴 편", "표준")가 짧은 코드로 담깁니다.
  • 담기지 않는 것: 얼굴 사진과 얼굴 측정값(비율·각도)은 링크, 문구, 이미지 어디에도 포함되지 않습니다.
  • 링크를 가진 사람은 누구나 그 결과를 볼 수 있습니다. 운영자는 링크나 그 내용을 받거나 저장하지 않습니다.

7. 아동의 개인정보

이 앱은 연령과 관계없이 개인정보를 수집하지 않습니다. 만 14세 미만 아동은 보호자와 함께 이용해 주세요.

8. 이용자의 권리

운영자는 개인정보를 보유하지 않으므로 열람·정정·삭제할 정보가 없습니다. 기기에 남은 앱 파일 캐시는 브라우저의 사이트 데이터 삭제나 앱 삭제로 지울 수 있습니다. Google과 GitHub가 처리하는 정보에 대한 권리는 각 회사의 방침에 따라 행사할 수 있습니다.

9. 방침의 변경

기능이 바뀌어 처리하는 정보가 달라지면(예: 광고나 통계 도구 추가) 이 페이지를 먼저 고치고 시행일을 바꿉니다.

English summary

"모두의 인성측정" is an entertainment app. It has no accounts and no backend, and the operator collects no personal data. Camera frames, selected photos and facial measurements are processed only on the device, are never uploaded or stored, and are discarded when the user leaves the result. The app uses Google's MediaPipe library for face detection; according to Google, input images stay on the device, while performance and usage metrics of the library are sent to Google. The website is served by GitHub Pages, which may process access logs such as IP addresses. A shared link encodes the scores and reading outcomes in its address so the recipient can view the full result; it never contains the photo or facial measurements. Contact: GitHub issues.
